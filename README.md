# Master Papers

Daily paper notes for recommender systems.

This repository is updated by a Codex daily automation. Each run adds:

- one Markdown note under `papers/YYYY-MM/`
- the paper PDF under `pdfs/YYYY-MM/`

## Paper Selection

The Codex automation searches for recommender-system papers and prioritizes venues in this order:

1. NeurIPS
2. ICML
3. ICLR
4. SIGIR
5. RecSys

It avoids papers that already appear in this repository and only selects papers with a downloadable open-access PDF.
